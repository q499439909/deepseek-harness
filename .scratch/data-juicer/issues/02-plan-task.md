# 02: 创建任务、澄清需求并审阅方案

**What to build:** 用户指定一个可访问本地数据路径并用自然语言提出目标，agent 检查少量数据、澄清需求并编排 recipe。Web 展示可跨轮次修改、重启后保留的方案卡；此票不启动实际数据处理。

**Blocked by:** 01 — 连接服务并查询算子

**Status:** ready-for-agent

- [ ] 一个完整处理目标创建一个处理任务，可跨多个会话轮次；同一会话最多保留一个未结束任务，多算子步骤不单独创建任务。
- [ ] 支持操作者有权限访问的任意本地输入路径；明确同机文件语义，不将 Workspace 归组当作租户隔离。
- [ ] 需求模糊时先追问；确认前仅允许格式、字段、算子参数和有界样本检查，不能执行变换、全量处理或模型/API 算子调用。
- [ ] 方案卡显示输入、算子顺序、重要参数和预期输出，支持展开完整 YAML、自然语言修改和执行前取消；在执行能力上线前不能提供可成功启动处理的操作。
- [ ] 每次修改保存不可变 recipe 版本，固定输入绑定、参数、生效配置及输出安排；旧版本不能被静默替换。
- [ ] 使用既有领域存储并在本部署路由到 SQLite；保存需求、输入、版本和状态，刷新及重启后恢复方案。
- [ ] 模型可见需求、方案和状态可从会话日志重建；明确领域记录与日志追加失败的恢复方式，会话 fork/导入不复制有效执行授权。
- [ ] 通过任务/API 行为和 Web 测试验证追问、跨轮次修改、取消、重启恢复、拒绝第二活动任务及确认前无数据处理；补 keyless 场景、必要 SDK 预期输出和真实 GUI GIF。
