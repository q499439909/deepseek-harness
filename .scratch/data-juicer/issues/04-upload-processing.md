# 04: 上传数据并完成处理

**What to build:** 用户在 DSH Web 上传一个数据集，agent 检查并生成方案；用户确认后实际处理上传数据并看到持久任务结果。

**Blocked by:** 03 — 确认方案并完成首次文本处理

**Status:** ready-for-agent

- [ ] 复用现有上传能力，将成功上传的数据复制到受管理存储并绑定当前会话/任务，不直接将客户端任意路径当作上传文件。
- [ ] 上传失败保留用户需求并提供重试，未完成上传不能成为有效输入；上传大小预算为可校验部署配置。
- [ ] 上传引用在刷新和重启后可恢复，其他会话的上传引用不能未经检查被当前任务使用。
- [ ] 上传数据沿用本地输入的有界检查、需求澄清、不可变方案、用户确认和一次执行规则。
- [ ] 实际 Data-Juicer HTTP 处理上传的文本数据，输出内容和清单正确且归属当前执行尝试。
- [ ] 上传或检查不会自动把完整文件加入模型上下文；只有允许的有界输入信息进入日志及模型请求。
- [ ] 验证小型真实上传处理、上传预算拒绝、失败重试、伪造引用、重启恢复和结果归属；补 keyless 模型场景及真实上传到结果的 GUI GIF。
