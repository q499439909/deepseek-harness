# 07: 处理图片并展示持久图片结果

**What to build:** 用户确认一条图片处理 recipe 后获得真实图片输出，在任务卡看缩略图、在现有侧栏分页查看全部输出图片，并可下载当次结果。

**Blocked by:** 06 — 预览与下载完整数据集

**Status:** ready-for-agent

- [ ] 使用小型本地图片数据集和真实 Data-Juicer recipe-flow HTTP 算子完成处理，不以假图片或 mock 处理代替验收。
- [ ] 对输出数据集引用的图片进行收集和保留；仅保存仍指向可变源图片的清单不满足产物保留要求。
- [ ] 图片关联任务和执行尝试，使用现有附件/图片规范化能力生成合适预览，并保留可下载的实际处理产物。
- [ ] 结果卡先展示数量有界的缩略图，现有右侧栏支持分页查看全部图片及打开单张图；加载量和尺寸预算可配置。
- [ ] 图片与数据产物的预览、下载均通过归属验证；图片预览不默认把整批图片发给模型。
- [ ] 原始图片移动或修改后保留结果仍可查看，DSH 重启后仍可访问；坏图、缺失引用及收集失败明确显示，不能误报完整输出。
- [ ] 用真实处理图片、附件/API 和 Web 行为测试核对输出、分页、保留及错误；验证 light/dark 主题并附真实图片处理结果 GIF。
