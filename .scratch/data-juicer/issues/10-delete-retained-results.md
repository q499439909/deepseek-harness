# 10: 删除保留结果并反馈产物缺失

**What to build:** 用户显式清理已保留的任务产物并看到更新后的可用状态；源数据不被删除，共享对象不影响其他结果，缺失或部分清理失败可理解并可恢复。

**Blocked by:** 07 — 处理图片并展示持久图片结果

**Status:** ready-for-agent

- [ ] 完成产物保留到用户显式删除，删除针对明确任务/产物范围，不自动删除本地输入或其他尝试结果。
- [ ] 对可能共享的附件对象按引用清理，删除一个任务不破坏其他任务仍使用的图片或文件。
- [ ] 不允许清理正在生成输出的执行尝试；未知尝试需要先核实状态，避免与仍运行服务端竞争。
- [ ] 数据库状态与文件清理之间失败可恢复，记录不可用/清理失败而不伪装完整成功；重试清理具有幂等行为。
- [ ] 历史会话仍能展示任务摘要与产物已删除状态，不保留可执行的旧下载链接；删除后 API 拒绝访问相应产物。
- [ ] 删除失败保留已有任务内容和可重试反馈；外部文件丢失在卡片、预览及下载中准确显示。
- [ ] 验证输入保持、共享对象、跨任务引用、部分清理失败、重启恢复和删除后下载拒绝；补 keyless 可见状态及真实 GUI 清理演示。
