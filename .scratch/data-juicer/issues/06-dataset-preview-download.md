# 06: 预览与下载完整数据集

**What to build:** 用户从已完成任务卡查看完整产物列表，在 DSH 现有右侧栏分页预览数据行并下载完整数据文件，刷新或重启后仍能访问保留下来的结果。

**Blocked by:** 03 — 确认方案并完成首次文本处理

**Status:** ready-for-agent

- [ ] 任务卡显示产物名称、类型、大小和可用状态，并用不透明产物引用打开预览/下载。
- [ ] 复用既有侧栏及文档预览组件，先支持已交付文本数据格式的有界分页；不把大数据集一次读入浏览器。
- [ ] 完整下载返回当次尝试保留的文件，与源数据之后的修改无关；不把浏览器路径直接用于任意文件读取。
- [ ] Host 验证任务、会话与产物关联，拒绝伪造、不属于所请求任务或已不可用的产物引用；首版仍是单操作者，不声称提供租户 ACL。
- [ ] 文件服务支持普通数据产物，不能仅用已有图片附件读取接口宣称完成数据下载。
- [ ] 单纯预览、翻页和下载不产生模型样本输入，也不记录完整数据集到模型上下文。
- [ ] 读失败保留结果卡已有信息并提供可行的重试，缺失文件有准确提示；上传/预览预算和输出位置遵循配置。
- [ ] 从真实处理结果经 API 到 Web 验证分页、完整下载字节、重启保留、引用拒绝及模型上下文不变；补真实结果浏览/下载 GIF。
