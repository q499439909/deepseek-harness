# 08: 展示整体统计与分析报告

**What to build:** 用户查看一次任务的整体处理效果，包括可获得的输入/输出数量、过滤数量、耗时、统计和警告，并查看经确认生成的 Data-Juicer 分析报告。

**Blocked by:** 06 — 预览与下载完整数据集

**Status:** ready-for-agent

- [ ] 结果卡展示有明确来源的整体统计，适用时展示算子阶段统计；不能从缺失指标编造数量或成功率。
- [ ] 处理结果和统计随任务持久保存，刷新/重启显示相同摘要；阶段顺序与已执行 recipe 对应。
- [ ] 分析调用沿用方案版本和用户确认流程，不能通过原始 analyze 工具绕过批准；一个完整目标的处理和已规划分析不被拆成每算子一个任务。
- [ ] 收集实际分析报告和图表为产物，右侧栏可查看并下载；HTML 等活动内容使用隔离预览。
- [ ] 缺失统计显示不可用，警告与处理失败分开；报告发布失败不能被当作完整任务成功。
- [ ] 统计摘要可以进入模型上下文，完整报告或数据集不会仅因 UI 打开而自动进入；明确选择内容的能力由后续票提供。
- [ ] 通过真实文本分析流程核对统计来源、报告预览/下载、缺失指标和失败反馈；复用 API/UI 测试，补模型可见快照及真实报告 GIF。
