# 09: 选择结果样本交给模型分析

**What to build:** 用户从数据预览或图片浏览中明确选择少量结果，要求 agent 分析这些样本；只有选中内容进入模型输入，普通浏览和完整数据集保持在上下文之外。

**Blocked by:** 07 — 处理图片并展示持久图片结果

**Status:** ready-for-agent

- [ ] 用户可选择数据行或图片并显式发起分析，交互复用既有侧栏和会话输入方式。
- [ ] Host 验证任务/产物关联及选中的行或图片，有界读取并拒绝伪造、不可用或预算超限的选择。
- [ ] 数据行只包含选中样本；图片使用持久附件引用。完整数据集、未选图片和内部存储路径不随选择自动加入模型请求。
- [ ] 样本来源、必要内容和图片引用写入会话日志，重建模型请求与回放时保持一致。
- [ ] 仅选择或翻页不会立即触发模型分析，明确提交才触发；重复提交和连接错误沿用既有输入语义。
- [ ] 模型不支持图片时有准确反馈，不丢失已保留的产物；不能用说明文字假装模型已经看见图像。
- [ ] 在 native/PTC 及必要 SDK 预期输出中验证实际请求内容与可重建日志；补 keyless 选中/未选输入用例、预算拒绝及真实 Web 选择分析 GIF。
