# Data-Juicer 数据处理用语

[English](glossary.md) | 中文

这些定义描述拟议的数据处理领域，不改变 DSH 中会话、轮次、Workspace 或后台任务的含义。

## 用语

**处理任务**：用户要求的一次完整数据处理目标，包含澄清、审阅、执行和结果查看，可以跨多个对话轮次。

_避免_：轮次、算子调用、后台任务

**Recipe 版本**：不可变的处理方案，指定输入绑定、算子顺序、参数、实际生效的处理配置和预期输出。

_避免_：可变的已确认方案

**确认**：用户对执行一个具体 recipe 版本的授权。

_避免_：agent 同意、任意数据处理的通用许可

**执行尝试**：将已确认 recipe 版本提交到处理服务的一次执行；重试是同一任务的另一次执行尝试。

_避免_：每次重试都创建新任务

**数据源**：选择为处理任务输入的上传数据或本地数据集。

_避免_：Workspace、租户

**产物**：一次执行尝试生成并保留的数据文件、图片或报告。

_避免_：路径字符串、完整模型回复

**结果摘要**：处理结果和可获得的汇总统计，与完整输出数据集分开。

_避免_：完整数据集
