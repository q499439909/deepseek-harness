# Triage statuses

English | [中文](triage-labels.zh.md)

- needs-triage: Requires evaluation.
- needs-info: Requires more information.
- ready-for-agent: Specified for agent implementation.
- ready-for-human: Requires human implementation.
- wontfix: Will not be implemented.

These values are local ticket statuses, not remote labels.

Readiness does not override unresolved ticket dependencies.
