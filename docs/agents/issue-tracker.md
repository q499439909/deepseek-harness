# Issue tracker: Local Markdown

English | [中文](issue-tracker.zh.md)

Specs live at `.scratch/<feature>/spec.md`.

Tickets live at `.scratch/<feature>/issues/<NN>-<slug>.md`, one file per ticket.

Publishing means writing local files, not creating GitHub Issues.

Fetch tickets by their referenced file path.

Record [triage status](triage-labels.md) near the top and dependencies under `Blocked by`.

Append discussion under `## Comments`.

For Data-Juicer, use `.scratch/data-juicer/` and preserve the existing ten tickets.
